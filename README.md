# Amrita Singh — Portfolio Website

A responsive, static portfolio website for Amrita Singh, Staff Software Engineer. It highlights backend platforms, distributed systems, event streaming, platform reliability and cross-team technical leadership.

## Files
- `index.html` — website content and structure
- `styles.css` — responsive styling and visual design
- `favicon.svg` — browser tab icon
- `Amrita_Singh_Resume.pdf` — résumé PDF used by the download links

## Publish for free with GitHub Pages
1. Download this package and extract it.
2. Open your repository: `https://github.com/einkal/amrita-portfolio`.
3. Choose **Add file → Upload files**.
4. Upload/replace `index.html`, `styles.css`, `favicon.svg`, and `Amrita_Singh_Resume.pdf` from this folder. Keep all four files in the repository root, not inside another folder.
5. Commit the changes to the `main` branch.
6. If GitHub Pages is already enabled, wait a minute or two and refresh the live site. If not, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.
7. Your website should be at `https://einkal.github.io/amrita-portfolio/` once GitHub Pages finishes deployment.

## Notes before publishing
- The site uses the professional email and GitHub profile listed on the résumé, but does not display phone number or residential address.
- All performance projections have been left off the public site; quantified points shown are based on supplied résumé content.
- Do not add internal system diagrams, customer information, credentials, tokens, private URLs or confidential implementation details.
- Review the role details and figures periodically to keep the portfolio current.

## Local preview
Open `index.html` in a modern browser. For a local HTTP preview, run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.
