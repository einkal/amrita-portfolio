# Amrita Singh — Portfolio Website

A responsive, static portfolio website based on the supplied October 2026 resume.

## Files
- `index.html` — complete website
- `Amrita_Singh_Resume.pdf` — downloadable resume linked from the site (included when available)

## Free hosting with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `amrita-portfolio`.
2. Upload `index.html` and `Amrita_Singh_Resume.pdf` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will show the public website URL in Settings → Pages. It usually looks like `https://YOUR-USERNAME.github.io/amrita-portfolio/`.

For a URL like `https://YOUR-USERNAME.github.io/`, name the public repository exactly `YOUR-USERNAME.github.io`.

## Before publishing
- Review the resume PDF that will be publicly downloadable.
- The public page uses the email and GitHub profile listed on the resume. It intentionally omits the phone number and residential address.
- Update the page when your role, skills, or resume changes.
